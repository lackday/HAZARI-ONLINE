# 🃏 হাজারী অনলাইন (Hazari Online)

৪ জন খেলোয়াড়ের রুম-কোড ভিত্তিক অনলাইন মাল্টিপ্লেয়ার হাজারী কার্ড গেম। একজন রুম বানাবে, ৫-অক্ষরের কোড পাবে, সেটা বন্ধুদের পাঠালে তারা ইন্টারনেট থেকে যেকোনো জায়গা থেকে জয়েন করতে পারবে। খালি আসনে বট (কম্পিউটার খেলোয়াড়) যোগ করে একাও প্র্যাকটিস করা যায়।

নিয়ম নেওয়া হয়েছে ঐতিহ্যবাহী হাজারী থেকে (Troy > Colour Run > Run > Colour > Pair > Indi, ৩৬০ পয়েন্টের ডেক, ১০০০ পয়েন্টে খেলা শেষ)। ছোট একটি সরলীকরণ আছে — নিচে "নিয়মের সরলীকরণ" অংশে বিস্তারিত আছে।

## ফোল্ডার গঠন
```
hazari/
├── server.js          ← Node.js + Socket.io ব্যাকএন্ড (সব গেম-লজিক এখানে)
├── package.json
└── public/
    ├── index.html     ← পুরো UI-র HTML কাঠামো
    ├── style.css      ← ডিজাইন
    └── client.js      ← ব্রাউজার সাইড লজিক (Socket.io ক্লায়েন্ট)
```

## ধাপ ১ — নিজের কম্পিউটারে চালিয়ে দেখা (ঐচ্ছিক কিন্তু সুপারিশকৃত)
আপনার কম্পিউটারে [Node.js](https://nodejs.org) (v18+) ইনস্টল থাকতে হবে।

```bash
cd hazari
npm install
npm start
```
তারপর ব্রাউজারে যান: `http://localhost:3000`
একাধিক ট্যাব/ইনকগনিটো উইন্ডো খুলে ৪ জন খেলোয়াড় হিসেবে টেস্ট করতে পারেন।

## ধাপ ২ — ফ্রি হোস্টিংয়ে আপলোড করা

⚠️ **গুরুত্বপূর্ণ:** এই গেমে সার্ভার সবসময় চালু থেকে সব খেলোয়াড়ের মধ্যে রিয়েল-টাইম সংযোগ (WebSocket) ধরে রাখে। **Vercel** মূলত সার্ভারলেস (প্রতি রিকোয়েস্টে আলাদা ইনস্ট্যান্স) হওয়ায় এই ধরনের persistent WebSocket সার্ভারের জন্য উপযুক্ত না। তাই নিচের যেকোনো একটি ব্যবহার করুন — দুটোই ফ্রি প্ল্যানে Node.js সার্ভার ২৪/৭ (কিছুটা স্লিপ-টাইমসহ) চালাতে দেয়:

### অপশন A: Render.com (সবচেয়ে সহজ, সুপারিশকৃত)
1. [github.com](https://github.com)-এ একটা নতুন রিপোজিটরি বানান এবং এই `hazari` ফোল্ডারের সব ফাইল আপলোড/পুশ করুন।
2. [render.com](https://render.com)-এ ফ্রি অ্যাকাউন্ট খুলুন (GitHub দিয়ে সাইন-ইন করা যায়)।
3. Dashboard → **New +** → **Web Service** ক্লিক করুন।
4. আপনার GitHub রিপোজিটরি সিলেক্ট করুন।
5. সেটিংস দিন:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
6. **Create Web Service** চাপুন। ২-৩ মিনিটে একটা লিংক পাবেন, যেমন `https://hazari-xxxx.onrender.com` — এই লিংকটাই এখন আপনার গেমের ঠিকানা, যা দিয়ে যে কেউ ইন্টারনেট থেকে খেলতে পারবে।

*নোট: Render-এর ফ্রি প্ল্যানে ১৫ মিনিট কেউ ব্যবহার না করলে সার্ভার ঘুমিয়ে পড়ে, পরের ভিজিটে জাগতে ~৩০-৫০ সেকেন্ড লাগতে পারে — এটা স্বাভাবিক।*

### অপশন B: Railway.app
1. একইভাবে GitHub-এ কোড রাখুন।
2. [railway.app](https://railway.app)-এ GitHub দিয়ে লগইন করুন।
3. **New Project → Deploy from GitHub repo** নির্বাচন করুন।
4. Railway নিজে থেকেই `package.json` দেখে `npm install` ও `npm start` চালাবে। ডিপ্লয় শেষে একটা পাবলিক ডোমেইন জেনারেট করে দেবে (Settings → Networking → Generate Domain)।

### অপশন C: Glitch.com (GitHub ছাড়াই, সবচেয়ে দ্রুত)
1. [glitch.com](https://glitch.com) → **New Project → Import from GitHub** (অথবা খালি Node প্রজেক্ট বানিয়ে ফাইলগুলো কপি-পেস্ট করুন)।
2. Glitch নিজে থেকেই `npm install` চালিয়ে অ্যাপ চালু করে দেবে এবং একটা `https://your-app.glitch.me` লিংক দেবে।

## কীভাবে খেলা হয়
1. যেকোনো একজন "নতুন রুম তৈরি করুন" চাপবে, একটা ৫-অক্ষরের কোড পাবে (যেমন `K7X2Q`)।
2. সেই কোড হোয়াটসঅ্যাপ/মেসেঞ্জারে বন্ধুদের পাঠাবে।
3. বাকিরা লিংকে ঢুকে নাম দিয়ে "যোগ দিন" চাপবে এবং কোড বসাবে।
4. ৪টি আসন পূর্ণ হলে (দরকার হলে বট দিয়ে) হোস্ট "গেম শুরু করুন" চাপবে।
5. প্রত্যেকে নিজের ১৩টি তাস ৪টি গ্রুপে (৪+৩+৩+৩) সাজিয়ে "প্রস্তুত (UP)" চাপবে।
6. সবাই প্রস্তুত হলে রাউন্ড ধরে ধরে ফলাফল দেখানো হবে, স্কোর যোগ হবে।
7. কারো স্কোর ১০০০+ হলে গেম শেষ, না হলে হোস্ট "পরবর্তী হাত" চেপে চালিয়ে যাবে।

## নিয়মের সরলীকরণ (Simplification Note)
আসল হাজারীতে খেলোয়াড় নিজের ৪টি গ্রুপকে (শক্তি অনুযায়ী নিজে) ক্রমানুসারে সাজায় এবং নিয়ম আছে যে ৪-তাসের গ্রুপ অবশ্যই সবচেয়ে দুর্বল হতে হবে। এই অ্যাপে সহজ ও দ্রুত খেলার জন্য:
- আপনি শুধু ঠিক করেন কোন ৪টি তাস "গ্রুপ ৪"-এ থাকবে এবং বাকি ৯টি তাস কীভাবে ৩টি গ্রুপে ভাগ হবে।
- সার্ভার নিজে থেকেই আপনার ৩টি ৩-তাসের গ্রুপকে শক্তি অনুযায়ী রাউন্ড ১→২→৩ এ সাজিয়ে দেয়, এবং গ্রুপ ৪ সবসময় শেষ রাউন্ডে খেলা হয়।
- তাই কৌশলগতভাবে দুর্বল ৪টি তাস "গ্রুপ ৪"-এ রাখাই ভালো, তবে অ্যাপ জোর করে সেটা যাচাই করে না।

বাকি সব স্কোরিং, তাসের শক্তি-ক্রম (Troy > Colour Run > Run > Colour > Pair > Indi), এবং ১০০০ পয়েন্টের নিয়ম আসল হাজারীর মতোই।

## সীমাবদ্ধতা
- গেমের অবস্থা সার্ভারের মেমোরিতে রাখা হয় (কোনো ডেটাবেজ নেই) — তাই সার্ভার রিস্টার্ট হলে চলমান রুমগুলো মুছে যাবে।
- কেউ গেম চলাকালীন সংযোগ হারালে, তার হয়ে অটো-সাজানো তাস জমা হয়ে যায় যাতে খেলা আটকে না থাকে।
